# Learning Objectives

By completing this lab, you will:

- Explain cloud computing in your own words.
- Identify cloud deployment models.
- Differentiate between IaaS, PaaS, and SaaS.
- Apply the Shared Responsibility Model.
- Choose appropriate cloud solutions for real-world scenarios.
- Practice communicating technical concepts.

Congratulations!

You have just joined Cloud Solutions Ltd. as a Junior Cloud Engineer.

Your manager has asked you to prepare recommendations for several customers who want to migrate to the cloud.

Instead of writing code, your task is to think like a cloud consultant and justify your decisions.
